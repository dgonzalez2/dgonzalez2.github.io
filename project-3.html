The Crimson Dungeon

A 2.5D FPS Rogue-like game set in a procedurally generated world

Project Overview

The Crimson Dungeon is a project I made as our university's final. Although the project was supposed to be made as a group we did not have enough peoplpe to form enough groups but I was given the green light to work on it as a solo developer. Despite our 3 month developement time for this project I pulled my best at the time to make something that was equal in the quality and scope to the other projects who had more teamates to work on it.
This game is a Rogue-like FPS game set in a procedurally generated levels where the player must fight, die and repeat to progress to higher levels but also find and upgrade their character with items found in these levels. Featuring a in-depth customization aspect where the main weapon and armour can be customized to the players liking.
This game has been developed entirely on my own as the sole developer on this project. I really love the old Doom games as such I was very inspireed to make a game that from the editor was 2D using tilesets, I managed to create a 3D envinroment for the player to navigate. Of course this came at the cost of not having a jump button but the game didn't need it. Being able to put all of this together on my own in 3 months was a huge undertaking but I managed to pull through to create something that I was truly proud of and hope to one day expand upon.

Features

At it's core The Crimson Dungeon features:
-Procedurally generated 2.5D levels
-Rogue-like elements
-A single boss fight
-Customizable Weapons and Armour
-Retro pixelated graphics similar to Doom
-First Person Perspective despite it being a 2D game at its core
